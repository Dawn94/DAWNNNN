# 俄罗斯方块（Tetris）

一个纯 HTML + CSS + JavaScript 实现的俄罗斯方块小游戏，无需任何依赖，双击 `index.html` 即可在浏览器中游玩。

## 玩法

- **← / →** 左右移动
- **↑** 旋转方块
- **↓** 加速下落
- **空格** 直接落底
- **P** 暂停 / 继续

## 运行

直接用浏览器打开 `index.html` 即可，或通过任意静态服务器托管（如 GitHub Pages）。

## 在线体验

启用 GitHub Pages 后，可在：`https://<你的用户名>.github.io/<仓库名>/` 访问。
